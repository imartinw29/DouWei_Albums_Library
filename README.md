# DouWei Albums Library

喜欢窦唯很多年，为这个一直沉浸在音乐创作的人，尽一些作为支持者的绵薄之力。

---

## 这个项目是什么

一个窦唯专辑档案站：从 1994 年的《黑梦》到最新的作品，按时间线整理每一张专辑——封面、发行信息、制作名单、幕后文字。

窦唯的特别之处在于，他的创作从未停歇。从黑豹时期到个人创作，从「不一定」「不一样」到「暮良文王」「朝简」，他始终在音乐里往前走，不太在意市场怎么想，也不太解释自己。作为听众，能做的就是把他的作品一份份收好、排齐、展示出来——像给一个持续创作的人建一座小小的档案馆。

## 内容

- 专辑档案：按年份排列，可按发行年份 / 专辑艺术家筛选
- 每张专辑包含：封面、艺术家、发行日期、介质、制作名单与介绍
- 数据持续更新：窦唯每出新专辑，都会收录进来

## 技术说明

- 纯静态站点，GitHub Pages 托管
- `index.html` — 官网首页（生平、乐队演变时间线、专辑入口）
- `albums.html` — 专辑列表页（年份 + 艺术家双筛选）
- `albums.json` — 专辑数据（唯一数据源，前端直接读取）
- `covers/` — 专辑封面图

## 维护

专辑数据由一份 Excel（`窦唯list.xlsx`）维护，新增专辑时只需在表中追加一行，其余（封面复制、JSON 生成、站点发布）由自动化流程完成。
